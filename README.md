# 🧮 Calculadora

Uma calculadora feita com HTML, CSS e JavaScript.

## 🚀 Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão

## 🛠 Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## 🎯 O que aprendi com este projeto

- Manipulação do DOM
- Eventos de clique
- Lógica de programação aplicada

## ▶️ Como executar o projeto

Basta abrir o arquivo `index.html` no navegador.
